# Offline Fallback

If the terminal, editor, or live page fails:

1. Show `broken/index.html` beside `expected/broken-report.json`.
2. Walk through the five evidence fields instead of running the script.
3. Show `repair.diff` or `repaired/index.html`.
4. Show `expected/repaired-report.json`.
5. Ask why the final status remains `INCOMPLETE`.
6. Reveal `manual-verification-checklist.md`.

The teaching point survives without GitHub, a browser extension, a token, or network access.
