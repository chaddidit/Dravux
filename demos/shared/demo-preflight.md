# Shared Demo Preflight

- [ ] Run every local command from a clean disposable state.
- [ ] Confirm expected broken and repaired reports match current output.
- [ ] Keep static evidence open before the audience arrives.
- [ ] Confirm no credentials, network, or publication step is required.
- [ ] Rehearse the manual-boundary sentence.
- [ ] Cap each demo at seven minutes.
- [ ] If a tool fails, preserve the error and switch to the fallback.
