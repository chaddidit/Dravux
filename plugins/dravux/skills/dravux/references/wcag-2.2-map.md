# WCAG 2.2 Routing Map

Use this map to locate likely criteria; it is not a substitute for the normative [WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/). Verify applicability, conformance level, exceptions, and exact wording before classifying a failure.

The current report contract accepts normative findings only for the criteria listed below. Treat an unmapped observation as `ADVISORY` or `INCOMPLETE` until the criterion, canonical fragment, and regression coverage are added together.

| Common barrier | Likely WCAG 2.2 criterion |
|---|---|
| Missing or unsuitable text alternative | 1.1.1 Non-text Content |
| Missing prerecorded captions | 1.2.2 Captions (Prerecorded) |
| Lost structure/relationships | 1.3.1 Info and Relationships |
| Color as the only signal | 1.4.1 Use of Color |
| Insufficient text contrast | 1.4.3 Contrast (Minimum) |
| Content does not reflow | 1.4.10 Reflow |
| Insufficient non-text contrast | 1.4.11 Non-text Contrast |
| Hover/focus content cannot be dismissed or retained | 1.4.13 Content on Hover or Focus |
| Keyboard-inoperable function | 2.1.1 Keyboard |
| Keyboard trap | 2.1.2 No Keyboard Trap |
| Illogical focus sequence | 2.4.3 Focus Order |
| Focus indicator not visible | 2.4.7 Focus Visible |
| Focused element obscured | 2.4.11 Focus Not Obscured (Minimum) |
| Small pointer target without an exception | 2.5.8 Target Size (Minimum) |
| Page language missing/incorrect | 3.1.1 Language of Page |
| Unexpected context change on focus/input | 3.2.1 On Focus / 3.2.2 On Input |
| Error not identified | 3.3.1 Error Identification |
| Missing label or instruction | 3.3.2 Labels or Instructions |
| Name/role/value unavailable | 4.1.2 Name, Role, Value |

## Classification guard

Inclusive design can identify important barriers beyond WCAG. Record those as `ADVISORY` unless target-specific evidence proves an applicable normative failure.
